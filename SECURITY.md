# Security Policy

## Supported Versions

This portfolio project tracks the `main` branch.

## Reporting Issues

Do not open public issues for sensitive security reports. Contact the repository owner privately with:

- Affected endpoint or file
- Steps to reproduce
- Expected and actual behavior
- Suggested mitigation, if known

## Notes

This project uses local sample data only. Before using it with real player, medical, or scouting data, add authentication, authorization, audit logging, encrypted transport, and environment-specific secret management.
